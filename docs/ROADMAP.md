## 判断の記録

大きな方針転換は、理由とともにここへ記録します。

| 日付 | 決定 | 理由 |
|---|---|---|
| 2026-08-06 | Sable のフォークをやめ、新規実装にする | 「軽さ」と独自デザインを本気で取るには、フォークを設定層で包む方針と両立しない |
| 2026-08-06 | Leptos + matrix-rust-sdk を採用 | 差別化として「Rust製」を掲げるため。初回ダウンロード量の優先度を下げる代償を受け入れた |
| 2026-08-06 | Tauri を排除し Web (PWA) のみにする | 無料の静的ホスティングで広く届けることを優先。実装の二重化を避ける |
| 2026-08-06 | VC を v0.2 へ回す | 「バグが無い」という差別化を守るため。v0.1 は外部リンクで逃がす |
| 2026-08-06 | Discord の配色・フォントを使わない | MIT で一般公開するため、トレードドレスの問題を避ける |
| 2026-08-06 | ライセンスを MIT にする | Sable フォークをやめ AGPL の義務から外れたため |
| 2026-08-06 | 先行プロジェクトからの文書引き継ぎをやめ、全て新規に書く | 前提が変わりすぎており、引き継いだ文書が現在の方針と噛み合わなかったため |
| 2026-08-06 | 見た目の参照元を Commet にする | Discord のクローンではなく、簡素でクリーンな質感を目指すため。構造は Discord、質感は Commet と役割を分けた |
| 2026-08-06 | 通信・同期・メモリ管理・暗号化をすべて Rust 側に置く | 「軽い」を実現する処理をUI層に漏らさないため。UI層は薄い表示層に徹する |
