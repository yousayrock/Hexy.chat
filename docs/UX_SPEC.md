# UX SPEC

画面ごとのUX規範、日本語文言、アクセシビリティ要件。

見た目（色・フォント・形状）は [DESIGN_LANGUAGE](DESIGN_LANGUAGE.md) が担当します。この文書は
**何を表示し、何を表示しないか / どう伝えるか**を決めます。

---

## 1. UX原則

- Discord に慣れた人が**操作を覚え直さなくていい**こと
- Matrix の専門用語をUIに出さない
- 重要な操作ほど見つけやすく
- エラーは日本語で、次の行動とセットで伝える
- 色だけに依存せず、文字や形でも状態を伝える
- キーボード、タッチ、スクリーンリーダーで操作できる
- 機能がないボタンを飾りで置かない

---

## 2. 用語変換

**内部コードでは Matrix 用語を使ってよいが、UIでは Discord 語彙を使う。**

| Matrix | UI表示 |
|---|---|
| Space | サーバー |
| サブスペース | カテゴリー |
| Room | チャンネル |
| Homeserver | 接続先 |
| User ID | あなたのID |
| Event | メッセージ |
| Device | 使用中の端末 |
| Sync | 更新 |
| Encrypted Room | 保護されたチャンネル |

## 3. 画面一覧（v0.1）

```text
起動
↓
セッション確認
├─ あり → メイン画面
└─ なし → ログイン画面

メイン画面（4ペイン）
├─ スペース（サーバー）バー
├─ チャンネル一覧
├─ タイムライン
└─ メンバー一覧

設定（最小限）
↓
ログアウト
```

v0.1 では以下の画面を作りません：新規登録、プロフィール編集、通知設定、暗号化設定、通話画面。

---

## 4. ログイン画面

### 表示するもの

```text
kaleido.chat のロゴ
「おかえりなさい」
あなたのID
パスワード
ログインボタン
別の方法でログイン（OIDC）
```

### 表示しないもの

```text
接続先（homeserver）  ← matrix.org 固定のため
device ID
Matrix という専門用語
```

### 入力例

```text
あなたのID
例: yuppi
```

Matrix ID 全体（`@yuppi:matrix.org`）が必要な場合も、内部で補完します。

### 状態

| 状態 | 表示 |
|---|---|
| ログイン中 | 「ログインしています…」ボタンは二重押下を防止する |
| 失敗 | 「ログインできませんでした。IDまたはパスワードを確認してください。」 |

**技術コードを表示しません。**

## 5. メイン画面

### スペース（サーバー）バー

- 参加している Space をアイコンで縦に並べる
- 未読があるサーバーは形でも分かるようにする（色だけに頼らない）

### チャンネル一覧

- カテゴリー（サブスペース）でグルーピングする
- テキストチャンネルは `#`、ボイスチャンネルは `🔊` を付ける
- **ボイスチャンネルは表示するが、v0.1 では通話できない**（[VC_SPEC](VC_SPEC.md)）
- 未読数を表示する
- 保護されたチャンネル（暗号化）は鍵のアイコンで示す

### タイムライン

- 上部：チャンネル名、メンバー一覧のトグル
- 中央：メッセージ一覧
- 下部：入力欄

**自分のメッセージと相手のメッセージは、色だけでなく配置や記号でも区別します。**

表示するもの：送信者名 / 本文 / 時刻 / 送信状態

### 入力欄

```text
プレースホルダー: 「#チャンネル名 へメッセージを送信」
```

v0.1 では添付・絵文字・GIFのボタンを置きません。機能がないためです。

### 送信状態

| 状態 | 表示 |
|---|---|
| 送信中 | 薄く表示 |
| 送信済み | 通常表示 |
| 送信失敗 | 「送信できませんでした。」＋ [再送] ボタン |

### メンバー一覧

- 表示名とアバターのみ
- オンライン状態は v0.1 では表示しない

### 空状態

```text
まだチャンネルがありません。

招待されたチャンネルがあると
ここに表示されます。
```

### 読み込み失敗

```text
チャンネルを読み込めませんでした。

[もう一度読み込む]
```

## 6. 設定画面（v0.1 の最小限）

```text
プロフィール概要（表示名・ID）
新しく作るチャンネルを保護する（ON/OFF）
接続先情報
ログアウト
アプリ情報・ライセンス
```

高度な Matrix 設定は表示しません。

### ログアウト確認

```text
ログアウトしますか？

この端末からログアウトします。

[キャンセル] [ログアウト]
```

## 7. エラー表示

`AppError`（[CORE_SPEC](CORE_SPEC.md) §10）をUI文言へ変換します。

| AppError | 表示 |
|---|---|
| `InvalidLogin` | IDまたはパスワードを確認してください。 |
| `InvalidHomeserver` | 接続先の設定に問題があります。 |
| `NetworkUnavailable` | インターネットに接続できません。 |
| `ServerUnavailable` | 現在、接続先を利用できません。 |
| `SessionExpired` | ログインの有効期限が切れました。もう一度ログインしてください。 |
| `PermissionDenied` | この操作を行う権限がありません。 |
| `EncryptionError` | このメッセージを安全に読み込めませんでした。 |
| `StorageError` | データを保存できませんでした。 |
| `InvalidInput` | 入力内容を確認してください。 |
| `NotInitialized` | 起動できませんでした。もう一度お試しください。 |
| `Unknown` | 問題が発生しました。もう一度お試しください。 |

**エラー表示には必ず次の行動を示します。**

## 8. オフライン表示

切断時：

```text
インターネットに接続されていません。
再接続を待っています。
```

**常時ダイアログではなく、画面上部の控えめなバー**を基本とします。操作をブロックしません。

再接続時：

```text
接続が戻りました。
```

短時間だけ表示して消します。

切断中も、既に読み込んだメッセージは読めます。

## 9. アクセシビリティ

**ターゲットが変わっても、この要件は維持します。**

- タップ領域は 44〜48px 以上
- 本文文字を小さくしすぎない
- 文字拡大時にレイアウトが壊れない
- コントラストを確保する（[DESIGN_LANGUAGE](DESIGN_LANGUAGE.md) の配色はこれを前提に選定）
- アイコンだけのボタンにはラベル（`aria-label`）を付ける
- スクリーンリーダーで操作できる
- 色覚差に配慮する。**状態を色だけで伝えない**
- 長押し必須の操作を避ける
- スワイプ必須の操作を避ける（スワイプは補助手段とし、必ずボタンでも到達できるようにする）

---

## 10. テスト

最低限、以下を確認します。

- ログイン画面の表示
- 入力必須チェック
- ログイン中の状態
- ログイン失敗の表示
- チャンネル一覧の表示
- 空状態
- タイムラインの表示
- 送信中の表示
- 送信失敗の表示
- オフライン表示
- ログアウト確認
- 各ブレークポイント（`base` / `md` / `lg` / `xl`）でレイアウトが壊れないこと

core層はモック可能なインターフェース越しに呼び出します。
